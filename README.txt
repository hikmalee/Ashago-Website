CARA UPLOAD:
1. Ekstrak ZIP ini.
2. Buat repository GitHub bernama ashago-website dengan visibility Public.
3. Upload SEMUA isi folder hasil ekstrak ke ROOT repository. Pastikan index.html berada langsung di root.
4. Buka Settings > Pages.
5. Pilih Deploy from a branch, branch main, folder /(root), lalu Save.
6. Tunggu deployment selesai dan buka URL GitHub Pages yang ditampilkan.

Logo dan ketiga foto produk sudah disertakan. Jangan pisahkan folder assets dari index.html.
