ASHAGO WEBSITE — GITHUB PAGES

ISI FOLDER
- index.html: halaman website utama
- assets/: tempat logo dan foto produk

SEBELUM UPLOAD
Masukkan file gambar asli ke folder assets dengan nama persis:
1. logo-ashago.png
2. foto-produk-1.jpg
3. foto-produk-2.jpg
4. foto-produk-3.jpg

Jika foto berformat PNG, ubah ekstensi di index.html agar sesuai, atau simpan ulang sebagai JPG.

CARA UPLOAD
1. Ekstrak ZIP ini.
2. Masukkan logo dan tiga foto produk ke folder assets.
3. Buka GitHub dan buat repository baru bernama ashago-website (Public).
4. Upload isi folder ini (index.html, README.txt, dan folder assets) ke root repository.
5. Di Settings > Pages, pilih Deploy from a branch, Branch main, Folder /(root), lalu Save.
6. Tunggu proses selesai dan buka URL GitHub Pages yang diberikan.

Catatan: foto dan logo asli belum dapat disertakan pada paket ini karena file gambar sumber tidak tersedia pada sesi pembuatan paket. Website tetap menampilkan nama ASHAGO sebagai pengganti logo sampai logo asli ditambahkan.
